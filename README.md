# 파종내비 — 농지 조건 기반 작물 추천 MVP

KRC AI 디지털혁신 공모전 서면심사 제출용 데모. 순수 HTML/CSS/JS로 만든 정적 웹페이지이며 백엔드·DB가 없습니다.

## 실행 방법
```bash
npm install
npm start
```
브라우저가 자동으로 열리지 않으면 `http://localhost:8080` 을 직접 열어주세요.
(또는 그냥 `index.html`을 브라우저로 더블클릭해서 열어도 되지만, 이 경우 `data/regions.json` 자동 로드가 브라우저 보안 정책(CORS)에 막힐 수 있어 `npm start` 사용을 권장합니다.)

## 구성
- `index.html` — 농지 조건 입력: 지역 선택 → 7개 지표 값 확인(읽기 전용, 지역 데이터로 고정) + 최근 병해충 발생 이력(직접 선택 가능, 지역 기본값 자동 채움) → 재배 면적 입력 → 추천 실행
- `result.html` — 추천 결과 + 손익 구조: 작물 랭킹(순위·이름·경고 문구만 표시, 점수는 화면에 노출하지 않음. 내부 정렬에는 계속 사용)과 작물별 매출/비용/보조금·손익 참고 범위(예: "80만원 ~ 100만원")·변동성 배지(안정적/보통/변동성 높음)를 한 화면에 표시
- `crop_matcher.js` — 8개 지표 스코어링 + 손익 계산 로직 (검증된 로직 그대로 사용, `<script src>`로 로드). 손익에 가격 변동성(`priceVolatility`)을 반영해 손익 참고 범위를 계산하는 부분만 확장했고, 8축 스코어링 공식 자체는 변경하지 않았습니다.
- `data/regions.json` — 표본 지역 5곳의 8개 지표 값. **지금은 전부 mock(임시) 값**이며, 실제 서비스 전환 시 흙토람·농업기상정보서비스·KRC 공공데이터 등에서 조회한 값으로 교체해야 합니다. 각 지역의 `source_note`에 출처를 남겨두었습니다.
- `styles.css` — 두 페이지가 공유하는 스타일

두 페이지는 실제로 페이지 이동(링크 클릭)을 하며, 선택한 지역·병해충 이력·계산된 추천 결과는 브라우저의 `sessionStorage`에 저장되어 페이지 간에 전달됩니다. 지역을 먼저 선택하지 않고 결과 페이지로 직접 들어가면 "지역을 먼저 선택해주세요" 안내가 표시됩니다.

## 사용법
1. "지역 선택" 드롭다운으로 표본 지역을 고르면 7개 지표 값이 지역 데이터 기준으로 고정되어 표시됩니다(직접 수정 불가). 최근 병해충 발생 이력은 지역 기본값이 자동으로 채워지되, 필요하면 직접 다른 값으로 바꿀 수 있습니다.
2. 재배 면적을 필요하면 조정하고 "추천 실행" → 추천 결과·손익 구조 페이지로 이동.
3. 작물 랭킹, 경고 문구, 매출/비용/보조금, 손익 참고 범위, 변동성 배지를 한 화면에서 확인할 수 있습니다.
4. 결과의 매출/비용/보조금/손익은 전부 참고용 mock 수치이며, 화면 하단에 안내 문구가 표시됩니다.
